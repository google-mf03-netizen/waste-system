📋 Google Sheets 串接設定說明

步驟一：建立試算表欄位

在你的 Google 試算表中新增工作表，命名為「清運紀錄」，第一列填入以下標題：

A1: 日期  B1: 填表人  C1: 回收商  D1: 可回收(kg)  E1: 不可回收(kg)  F1: 金額(NT$)  G1: 類型  H1: 說明  I1: 建立時間

步驟二：開啟 Apps Script

  1. 在試算表頁面點選上方選單「擴充功能 → Apps Script」
  2. 刪除編輯器中的所有內容，貼入以下程式碼：
const SHEET_NAME = '清運紀錄';

function doPost(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheetByName(SHEET_NAME);
    const data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.date, data.user, data.vendor,
      data.recyclable, data.non, data.amount,
      data.type, data.desc,
      new Date().toLocaleString('zh-TW')
    ]);
    return ok({status:'saved'});
  } catch(err) {
    return ok({status:'error', message: err.message});
  }
}

function doGet(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheetByName(SHEET_NAME);
    const rows = sheet.getDataRange().getValues();
    rows.shift(); // 移除標題列
    const data = rows.map(r => ({
      date: r[0], user: r[1], vendor: r[2],
      recyclable: Number(r[3]), non: Number(r[4]),
      amount: Number(r[5]), type: r[6], desc: r[7]
    }));
    return ok(data);
  } catch(err) {
    return ok({status:'error', message: err.message});
  }
}

function ok(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

步驟三：部署為網頁應用程式

  1. 點選右上角「部署 → 新增部署」
  2. 類型選「網頁應用程式」
  3. 執行身分：「我」
  4. 存取權：「所有人」（若限公司內部可選「公司內所有人」）
  5. 點「部署」，複製產生的網址

步驟四：填入網址

用文字編輯器打開本 HTML 檔案，找到開頭的 SCRIPT_URL，將其中的文字替換成剛複製的網址，存檔即完成。
